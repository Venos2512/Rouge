# Upgrade Choice thành scene UI

## Thay đổi
- Chuyển backdrop, panel, title và 3 upgrade card thành node trong `upgrade_choice_ui.tscn`.
- Script chỉ cập nhật dữ liệu lựa chọn và xử lý click/phím 1-3.

## Cách kiểm thử
- Mở `res://gungeon_proto/scenes/ui/upgrade_choice_ui.tscn` để chỉnh layout/card.
- Mở chest hoặc trigger upgrade đầu trận, chọn bằng click hoặc phím 1/2/3.
