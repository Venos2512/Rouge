# SFX

Đặt các hiệu ứng âm thanh của game trong thư mục này.

Ưu tiên định dạng `.ogg` hoặc `.wav` và đặt tên file bằng `snake_case`, ví dụ:

- `pistol_fire_01.wav`
- `sword_hit_01.wav`
- `enemy_death_01.ogg`
- `coin_pickup.wav`

Nhạc nền và ambience nên đặt ngoài thư mục này để có thể điều khiển bằng audio bus riêng.
